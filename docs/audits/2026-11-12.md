# Audit 2026-11-12: outdated and irrelevant code and tests

Base: M02 delivered plus the schema consolidation.

This audit looks only for bloat: outdated or irrelevant code, tests, scripts and repository material.
It does not cover bugs, architecture or performance; for those, see `2026-11-10.md`, `2026-11-10-2.md`
and the open items of `2026-11-11-implementation-handoff.md`.
Finding numbers start again at #1 and are local to this file.

Method:
- **Review:** five reviewers.
  - Two covered tests (files `a`–`l` and `m`–`z`, plus hardware and manual).
  - Three covered dead code and redundancy: backend (`capture`, `pipeline`, `platform`, `search`,
    `storage`), app shell (`api`, `ui`, top-level modules, `scripts/`, `packaging/`), and `eval/` with `docs/`.
- **Verification:** four refuters checked every MUST and every SHOULD that deletes something.
  - 38 items were checked: 3 refuted, 16 narrowed (marked *narrowed*), and the rest stand.
- **Known findings:** open items of the 2026-11-11 handoff were skipped or are marked (recurring).
- **Timing of `eval/` and `docs/` work:** under DECISIONS.md:49 (2026-11-12), audits, baselines, method
  reports and `eval/` stay in place until the current cleanup ends. Findings there are marked *after
  cleanup*.
