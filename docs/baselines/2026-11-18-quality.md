and per-cell coverage: `eval/quality/results/<run-id>/`. Numbers are comparable only with runs of
the same machine id. Rescored on 2026-11-20 with a fixed scorer: see
[the last section](#rescore-with-the-2026-11-20-scorer) for the values that changed.

right and left 2560x1440; Wave:3 mic, DT-770 PRO default output, Wave Link virtual endpoints,
VB-CABLE as the harness's mic; Windows OCR en-US and fr-FR.

What these smoke numbers already say (to explain in Phase 2, not yet findings):

- **Akashic lists itself as a sound source** (M7.1, 17 of 17 system segments): its loopback
  capture is an audible session on the recorded endpoint, and `_audible`
  (`src/akashic/platform/win/audio.py:544`) has no own-process filter.
- **App time is cut to stored frames** (M5.1 about 110 of 300 s holes, M5.3 error 0.57): an app
  session ends at its last stored frame (`pipeline/sessions.py:53-73`), so with the 60 s game-mode
  screenshot interval the game shows as instants.
- **Games split on every voice-chat visit and then vanish** (M6.1, M11.1 game F1 0): the 0.9-105.9 s
  game was stored as two rows around a Discord visit, neither reaching the 2 min episode minimum.
- **Overlapping speech is mostly lost** (M9.1 overlap WER 0.75, M8.1 overlap recall 0.41): a
  French video under an English call keeps one language.
- **Small fonts and 1440p side monitors** read badly (M3.1 CER 0.41-0.45 at ≤ 11 device px, 0.40 at
  1440p vs 0.02-0.04 at 4K); deferred game-mode OCR CER 0.47-0.51.
- **Media rows open at the first poll after play** (M6.1 0.09-0.26 s). Revised 2026-11-19: the first scoring read 16 s because the video started during the scenario's 60 s Pause, when Akashic records nothing by design; the scorer now moves a truth start inside a no-recording gap to its end.
- **Guardrails while gaming**: worker and llama-server hold about 4.3 + 4.7 GB of VRAM;
  synthetic game p99 frame time 0.61 → 1.02-1.08 ms with Akashic (uncapped at about 3,800 fps).
- Privacy held: 0 canary hits in SQL, frames, logs, temp files and the data folder, 0 plaintext
  files, 0 outbound connections.

## Rescore with the 2026-11-20 scorer

All five runs were rescored on 2026-11-20 from their saved stores; `src/` and the drives are
unchanged, only `eval/quality/score.py` and `tags.py` changed. The tables above keep the earlier
scorer's values; where this table gives a different value, this one holds. Rows not listed here
did not change. Old → new; a single value means unchanged.

What changed in the scorer:

- **M3.1, wrap-tolerant:** a shown line is matched against each stored line and against every run
  of 2-3 consecutive stored lines joined, so a line that OCR wrapped is no longer counted as
  misread (found by the small-text OCR study).
- **M6.1 and M11.1, truth the store could hold:** each video play and game session is clipped to
  the first stored frame and the drive end, split at the driver's Pauses, pieces under 60 s
  (video) or 120 s (game) dropped, and each stored row given to the one piece it overlaps most.
  M6.1 game now counts only rows of the game's own process (Outer Wilds rows were mixed into the
  synthetic game's before). New fields: `truth_pieces`, `missed_pieces`, `rows_not_on_truth`,
  `rows_per_truth` (mean, max), `split_rows`. Smoke's game (105 s) is under the 120 s floor, so
  its game cells are now empty.
- **M9.1:** truth utterances at least half inside a driver Pause are left out and reported as
  `speech_paused`; overlap groups are scored per speech app when every segment names exactly one
  (Discord or a browser).
- **M8.3:** the truth speaker is taken from the segment's own speech app when that app spoke
  there. It changed no author on these runs.
- **M10.1:** the solid-square canary rule (2026-11-19) is now in the stored scores: 0 hits on
  every run.
- **Speed (exact, scores identical to the slow version):** bit-parallel Levenshtein with an early
  bound, best-line search by length gap, per-text memo, frames decoded on a thread pool, the
  tag decoder's dark runs found in one vectorised pass, and one-pass needle search in M10.
  Scoring time: standard 55 min → 75 s, day about 3 h → 412 s, smoke 7 s.
